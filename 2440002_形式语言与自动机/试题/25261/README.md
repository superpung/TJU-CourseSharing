注：基本上很多题目都是有好几种做法，例如DFA转RE，删除状态的顺序不同得到的就不一样。泵引理证明部分不用和ppt完全一样，只要理解了，写的合理就行，包括最后一道证明题，也不用和作业的答案一样。

虽然题目都是英文，但你做了这么多作业，看了这么多ppt，肯定一看就知道。

不知道这门课的题目会不会每年都改，但不管怎么改，都是很简单的，都是出自ppt和作业，有很少的不是原题的，方法都一样。

最后一道是难度提高的证明题，但还是出自作业，原题，做作业的时候可以自己判断一下哪些可能会出。如果你看某一年的卷子里面最后一道题不是作业里的，不用担心，肯定是**当年**的作业里面的。

下面是2025.11.20上的最后一节复习课做的笔记，可以参考。

> 复习，形式语言这一章，主要掌握基本的定义，句子，句型，语言，重要的是文法，四元组定义。什么是语言，由文法推出的全部句子集合，由文法到语言，由语言到文法，看看ppt，作业掌握就可以。乔姆斯基分类，要求掌握。ppt后面那个0型文法的例子不要求。
> 正则语言，几种等价形式变换。DFA定义，五元组。给出转移图，写出五元组定义，反过来，给出五元组定义，画图。给一个转移图，写出语言描述，给语言，画出DFA，这种题没有固定的公式推导，只要掌握例题作业就可以，因为这个非常多，不可能穷尽，但是有些类型可以套用。正则运算，封闭性。NFA定义，五元组，和DFA区别。给NFA，要会构造等价的DFA，这个要会做，肯定会出的。正则运算封闭性，具体证明不要求。正则表达式，定义，给正则表达式，描述对应的语言，掌握ppt例子就可以。给正则表达式构造自动机，从最基础的开始，一步一步构造，不需要化简，这个要考察。给DFA，转换成正则表达式，要把DFA转换成GNFA，等等，这个证明不要求，不用化简，这个要出题，由DFA到正则表达式。正则语言的泵引理，这个要理解，证明某个语言不是正则的，讲过的例题加上作业题，要求，但是不一定原封不动的出，要掌握这个证明的套话。FA和RG的等价，这里要会转换就可以了。变元相当于状态。给一个正则文法，转成NFA，给DFA，转成等价的文法。正则语言就这些。
> 上下文无关语言，二义性不要求，语法分析树，可以看一看。要求乔姆斯基范式，要会转换。重点是下推自动机，定义要求掌握，下推自动机的状态转移图的画法，掌握到例子就可以了，给语言，画出PDA。上下文无关语言和PDA等价的，这一部分有一个给CFG，画出PDA，这个要求。上下文无关语言的泵引理不要求。
> 图灵机，定义7元组，要求。ppt的例子要掌握，w#w那个。多带图灵机等等，这些都不要求。书上还有另一个例子，02n，这个例子要求。还有图灵机的格局，这个要会画，以及几种语言的关系，那个韦恩图，要知道。
> 作业里面，有一些内容。作业2，正则语言在交运算也封闭，可以构造自动机，还有not in，构造一个in，然后补操作就可以了，这些自动机自己掌握构造就可以了。第7题这样的题目就是提高的，有一个串，逆过来，如果有一个语言A是正则的，逆过来还是正则的。这些都是构造性证明。第8题，完美洗牌。13题，fst这个也比较简单。15题，这个是反例，能画出来自动机，就可以了，证明不要求。后面就是泵引理了，满足泵引理，不一定是正则语言。关于正则语言，和数学归纳法相关的，给语言，写出文法，不用过多担心。最后一个题目是证明题，也在复习范围里面，就是ppt例题，作业。但是会改一点点，思路还是一样的。1819年的考试卷子，有些相似的地方，也有不相似的，给语言，构造写4元组，这个不要求。给文法，证明语言是某个，这个也不要求。
