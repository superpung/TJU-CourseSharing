# 形式语言与自动机

## 25261学期  王鑫  2学分

### 简介

选修课，主要讲述有关形式语言和自动机方面的内容。

教材《计算理论导引》第一章，第二章部分内容，第三章部分内容，以及补充内容

### 平时

点名+作业+上机实验

上机实验就是和《知识工程》一样，跟着要求做，然后截图，不用做更多的。要注意截止时间。一共三次

### 期末

闭卷考试，95分钟（一节课），时间足够。

英文题目，作答中英文皆可。

没有选择判断填空，都是大题。

### 经验

复习的时候不要光看作业，还要看看ppt

建议上课要听听讲，考试题的最后一道会从作业里面出。

### 评价

期末考试很简单，只要看看ppt和作业肯定都会的，而且比较容易学。

没有复杂的实验也没有大作业，期末考试也挺简单，总体来说比较省事。
