# 自然语言处理

## 25261学期  贺瑞芳(教授)

### 简介

应该是讲的很古老的那种自然语言处理，和现在的大模型不是一个东西

### 平时

有点名回答问题，老师很严格，因为选课晚导致少上一次课都能说成旷课

第一个作业是根据自己的兴趣，写一个某某方向的综述

第二个作业是选一篇顶会论文阅读，写笔记，做ppt，做汇报，像研究生组会那样

### 大作业

就是自己对什么感兴趣，做一个项目。老师也会给选题推荐

最后需要ppt线下汇报，然后每个人要写一份自己的报告，一个小组也要写一份总的报告
