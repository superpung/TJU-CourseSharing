# 网络安全

## 26271 学期 张蕾

### 简介  

网安必修课，其余智算专业选修，开的比较新，去年广受好评。

### 平时

大作业30% + 实验20%

看似没有点名分，但是老师会突然抽人回答问题，没答上坐下无事发生，让下个人来，直到答上为止。要是没来会在你名单上打个X。

大作业今年的题目见附件。每组汇报完下面的同学可以提问，提问完在老师名单上打√。**所有组汇报完后没提问的人会少平时分。**

实验是在网安靶场上做，宝宝题，跟着操作就行了。其他专业四次，网安的同学6次。

### 期末

占比50% 

10道简答，一题10分。

考试前一定要看她给的重点问题！！！你懂的\^_\^ 可以AI回答，再背下来，也可以自己在PPT上找，但不一定能找全。AI回答的和PPT上的不一样也不要紧，她说都给分。

### 评价

课程前四章主要是复习计算机网络的知识，给没学计网的同学大致讲一讲。后面六章是重点，知识点其实不少。

免听方面可以申请，但是流程可能比较曲折。

复习倒是没什么压力，总体来说给分高 + 事有点多，看自己需求吧，总的来说肯定是好课 + 好老师。
