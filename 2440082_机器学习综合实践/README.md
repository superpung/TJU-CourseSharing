# 机器学习综合实践

## 25261学期  王煜  1.5学分

### 简介

这是一门AI同学们上的课程设计类的综合实践，大三上学期开学的暑期小学期。小学期共三周，这个任务占前一周半

主要是在kaggle发布一个任务，同学们基于这个任务进行打榜。

一个小组最多5人

### 成绩

打榜的排名+课程报告

### 经验

这个学期发布的任务是一个异常检测的任务，训练集只有正常的图片，而测试集含有异常图片，训练神经网络，区分这两者。

数据集是mvtec_ad的一个子集。

最好看看现有的论文，复现或者复用论文的代码，然后做一下适配，不要自己造航母。我用的PatchCore，效果还不错，分数是0.989。

评价的指标是AUROC，在提交的csv文件里面，你可以把它当成二分类的，标签就是0/1，更推荐的是直接把异常分数当成label，这样根据你异常分数计算，也可以算出AUROC，具体可以自己学习一下。

在kaggle上面，一个账号一天只能提交3次，你可以注册多个账号。

可以子自己下载mvtec_ad_subset数据集，然后自己测试，得到.csv文件，这样直接交就可以了，不用在kaggle上面提交notebook，这个平台的算力比较低。

### 评价

只要是打榜类的，就必定会刷分，这个学期有同学刷的非常狠，基本上有很多0.999这种的。

由于上个学期有同学为了刷分直接想办法一个一个测试，最后试出来测试集的分布，所以这个学期就只发布了验证集，在时间限定范围内，分数只有验证集的分数（public score），测试集分数（private score）看不到，只有截止了才能看到最终的分数。但是即使这样，使用的测试集还是kaggle上面的mvtec_ad_subset数据集，而这个数据集是公开的，可以直接下载到他，要是直接把测试集的label交上去还是满分。
