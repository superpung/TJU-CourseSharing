### 简介

你们此时已经知道了语音信息处理是啥

### 任务

做一个语音信息处理全流程的一个项目，包括语音识别，自然语言处理，文本转语音，再加上声纹识别，说话人识别，语音增强，去噪之类的。类似于小爱同学那样的助手。

会发一个树莓派和麦克风和音响

模型尽量本地部署，可以部署在自己笔记本上，然后弄成API，让树莓派调用，也可以在auto DL上面部署，也可以直接调用云端大模型API，不过这种方式不能体现自己的工作量，所以分数低一点。

小组的人数尽量多一点，任务比较重，同时注重分工要合理。

需要进行3阶段的ppt汇报，包括选题阶段，中期阶段，最终汇报。最终汇报的时候要现场演示或者录制视频（具体忘记了）

可以想一个有创新一些的点子，比如做一个反诈识别的东西，先识别这是诈骗，然后和对方周旋，拖时间浪费对方精力（这个点子已经用掉了）。

最后全组写一个报告，同时每个人写一个报告，同时要打包整个项目
